# Renu Arya — Portfolio Site

A clean, minimalist portfolio website for **Renu Arya**, a Cognitive Science Researcher specializing in EEG/fMRI analysis, computational modeling, and Bayesian statistics.

## Structure

```
renu-arya-portfolio/
├── index.html          # Main portfolio: about, experience, projects, skills
├── publications.html   # Publications page
├── cv.pdf             # Two-page CV
├── README.md          # This file
└── LICENSE            # MIT
```

## Features

- Clean black-and-white minimalist design (inspired by nishadsinghi.github.io)
- Responsive layout that works on mobile and desktop
- No JavaScript required — pure HTML/CSS
- Links to GitHub, LinkedIn, and publications
- SEO-friendly with proper meta tags

## Development

This is a static site — just open `index.html` in any browser. No build step required.

## Deployment

Designed for GitHub Pages. Enable in repo settings:
- Source: `main` branch
- Folder: `/ (root)`
