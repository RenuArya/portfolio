# fMRI Network Neuroscience Analysis

## Overview

Research processing 200+ fMRI datasets to build a comprehensive network neuroscience analysis pipeline for identifying disease-related connectivity patterns in Alzheimer's patients.

## Methods

- **Data Processing**: MATLAB with neuroimaging toolboxes (SPM, CONN)
- **Resting-State Analysis**: Functional connectivity matrix extraction
- **Graph Theory Metrics**: Degree centrality, clustering coefficient, modularity
- **Comparative Analysis**: Healthy controls vs. Alzheimer's cohorts

## Pipeline Steps

1. **Preprocessing**: Slice-timing correction, realignment, normalization, smoothing
2. **Denoising**: Physiological noise regression, motion scrubbing
3. **Connectivity Analysis**: ROI-to-ROI functional connectivity matrices
4. **Graph Theory**: Network metric computation using Brain Connectivity Toolbox
5. **Statistical Analysis**: Between-group comparisons using permutation tests

## Tools & Libraries

- MATLAB + SPM12
-CONN Toolbox
-Brain Connectivity Toolbox
-R (for statistical analysis)

## Results

Identified significant differences in:
- Degree centrality in default mode network regions
- Clustering coefficients in memory-related circuits
- Modularity patterns in posterior cingulate cortex
