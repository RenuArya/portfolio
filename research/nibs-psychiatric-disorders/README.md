# NIBS Psychiatric Disorders Research

## Overview

Research investigating neurological and clinical impacts of non-invasive brain stimulation (tDCS) across psychiatric disorders including ADHD, OCD, and Depression.

## Objectives

1. **Biomarker Identification** from EEG data to predict treatment response
2. **EEG Data Acquisition** protocol development and optimization
3. **Signal Processing & Analysis** pipeline implementation
4. **Systematic Review** of existing literature on neurostimulation for psychiatric interventions

## Technical Stack

- **EEG Processing**: MATLAB, EEGLAB, custom preprocessing scripts
- **Analysis**: Python (SciPy, MNE-Python)
- **Statistics**: R (lme4 for linear mixed models)
- **Documentation**: LaTeX for manuscripts and grant proposals

## Key Contributions

- Developed standardized EEG preprocessing pipeline for tDCS studies
- Identified potential biomarkers for treatment response prediction
- Contributed to systematic review manuscripts
- Drafted grant proposals for continued research funding

## Data Scale

- 200+ EEG sessions from clinical trial participants
- Multi-session per-participant measurements
- Multiple psychiatric disorder cohorts (ADHD, OCD, Depression)
